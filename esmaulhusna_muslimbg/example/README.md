# Example app

This example demonstrates how to use `esmaulhusna_muslimbg` inside a Flutter application.

## What it shows

- Loading Esmaul Husna data with `EsmaulHusna.getNames`
- Rendering Arabic text, localized name, and translation
- Working with locale codes such as `bg`, `en`, `tr`, `bs_BA`, `mk_MK`, `sq_AL`, and `sq_XK`

## Import

```dart
import 'package:esmaulhusna_muslimbg/esmaulhusna_muslimbg.dart';
```

## Run the example

```bash
cd example
flutter pub get
flutter run
```
